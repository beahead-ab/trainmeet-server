# pdf-lib 1.17.1

Används av Inställningar → Lokförare för att dela köruppdragens PDF i en liten
PDF per tjänst, i administratörens webbläsare, så att föraren bara får sin
tjänsts sidor (ett par hundra kB i stället för hela häftet). Servern själv
tolkar ingen PDF.

Källa: npm-paketet `pdf-lib@1.17.1`, filen `dist/pdf-lib.min.js`, oförändrad.
Licens: MIT (`LICENSE-pdf-lib.txt`).

Uppdatera: `npm pack pdf-lib@<version>`, kopiera samma fil hit och ändra
versionen här och i `lokforaren-koruppdrag.js`.
