FÖR DIG SOM PROVAR

Prova en hel tågrörelse

  1. På Charlottendal: börja skriva 39. # väljer tåget; nästa # begär klartecken.
  2. På Vagnsta: skriv 39 #. Nästa # ger klart. * öppnar ”Neka?”; # bekräftar.
  3. Tillbaka på Charlottendal: # rapporterar faktisk avgång.
  4. På Vagnsta: # tar emot på spår 1. För annat spår: B → D → #.

17 går från Charlottendal till Munkeröd. 93 går från Munkeröd till Charlottendal. Alla är exempel, inte er riktiga tidtabell.

C / D bläddrar bakåt/framåt bland avgångar och aktiva inkommande tåg, i tidtabellsordning. En framtida ankomst blir valbar först när avsändaren har begärt tåget eller reserverat det i direkttrafik. ANK / AVG och planerad tid visas på rad ett. # väljer; ingen trafik ändras av själva valet. I listan växlar A mellan alla valbara tåg, aktiva ankomster och avgångar. Tidtabellen under boxen är en referens och visar även framtida ankomster.

# bekräftar, * avbryter eller går tillbaka. När du skriver tömmer * numret lokalt. Vid egen begäran eller eget klartecken öppnar * ”Återta?”; vid inkommande begäran öppnar den ”Neka?”. Först # i frågan ändrar trafiken; * i frågan behåller läget. A visar då översikten utan att ändra trafiken. Efter faktisk avgång kan tåget inte återtas. Klockan längst ned är alltid den aktuella träffklockan.
