FÖR DIG SOM PROVAR

Prova en hel tågrörelse

  1. På Charlottendal: börja skriva 39. # väljer tåget; nästa # begär klartecken.
  2. På Vagnsta visas förfrågan automatiskt om boxen står i översikten. # ger klart. * öppnar ”Neka?”; # bekräftar. A hittar alltid tillbaka till förfrågningskön.
  3. Tillbaka på Charlottendal: # rapporterar faktisk avgång.
  4. På Vagnsta: # tar emot på spår 1. För annat spår: B → D → #.
  5. Avsändaren får 39 MOTTAGET med mottagarens kod. Beskedet försvinner efter fem sekunder utan kvittering. Det färdiga tåget visas inte längre på avsändarens aktiva display. Annat pågående arbete avbryts inte; beskedet väntar tills översikten visas.

17 går från Charlottendal till Munkeröd. 93 går från Munkeröd till Charlottendal och 94 från Vagnsta till Charlottendal. Begär 93 och 94 från respektive avsändare för att prova två samtidiga förfrågningar. Alla är exempel, inte er riktiga tidtabell.

A = förfrågningskö i alla vyer, även om du tappat bort dig. Räknaren 1/2 betyder första av två väntande förfrågningar. C/D bläddrar bara i kön när den är öppen. # ger klart för tåget som visas; B går till översikten utan att svara. Efter ett svar ligger det tåget kvar; A öppnar återstående förfrågningar. Ny förfrågan avbryter inte ett pågående tågval eller inmatning. Trycker du själv A under inmatning lämnas det oskickade numret och kön öppnas.

C / D från översikten bläddrar bland avgångar och aktiva inkommande tåg, i tidtabellsordning. En framtida ankomst blir valbar först när avsändaren har begärt tåget eller reserverat det i direkttrafik. ANK / AVG och planerad tid visas på rad ett. # väljer; ingen trafik ändras av själva valet. I tidtabellslistan växlar B mellan alla valbara tåg, aktiva ankomster och avgångar. Tidtabellen under boxen är en referens och visar även framtida ankomster.

# bekräftar, * avbryter eller går tillbaka. När du skriver tömmer * numret lokalt. Vid egen begäran eller eget klartecken öppnar * ”Återta?”; vid inkommande begäran öppnar den ”Neka?”. Först # i frågan ändrar trafiken; * i frågan behåller läget. B visar då översikten utan att ändra trafiken. Efter faktisk avgång kan tåget inte återtas. Klockan längst ned är alltid den aktuella träffklockan.
